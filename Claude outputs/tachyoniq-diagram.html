⚠ CRITICAL INVARIANT — NEVER MOVE:  SQLValidator.validate() runs inside the SQL repair loop, before every execution attempt. A security violation triggers an immediate halt with zero retries — no retry logic, no LLM re-generation, no fallback. The DiagnosticRepairAgent (proposed, Phase A) wraps only SQL-syntax errors; it calls SQLValidator again on each attempt before executing. This invariant must survive all future refactoring.

class RoutingStrategy(str, Enum):
    SEMANTIC_LAYER = "semantic_layer"
    LLM_SQL        = "llm_sql"
    HYBRID         = "hybrid"

class AmbiguityOption(BaseModel):
    label:      str
    sql_filter: str
    confidence: float  # 0.0–1.0

class StructuredAmbiguity(BaseModel):
    field:   str
    options: list[AmbiguityOption]
    question: str

models/evidence.py — New file
class EvidenceNodeType(str, Enum):
    METRIC · SEGMENT · EVENT
    ANOMALY · HYPOTHESIS · CONCLUSION

class EvidenceEdgeType(str, Enum):
    CAUSES · CORRELATES
    EXPLAINS · CONTRADICTS

class EvidenceNode(BaseModel):
    id:        str
    type:      EvidenceNodeType
    label:     str
    value:     float | str | None = None
    confidence: float
    sql_query: str | None = None

class EvidenceGraph(BaseModel):
    root_question:  str
    nodes:          list[EvidenceNode]
    edges:          list[EvidenceEdge]
    top_conclusion: str
    confidence:     float
